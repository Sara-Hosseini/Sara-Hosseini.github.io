Product Analytics Case Study

Funnel · Retention · A/B Testing in SQL, Python & Power BI

Portfolio project on a simulated European mobility app. I generated the data for this project (fixed random seed, no personal data), so the results show the analytical method, not real business outcomes.

Business Questions

  1. Where in the journey do users drop out before booking?
  2. Which acquisition channels and platforms bring valuable users?
  3. How well do monthly signup cohorts retain, and which behaviours go with retention?
  4. Did the simplified booking flow improve conversion enough to roll out?

SQL Example: Funnel Drop-off with Window Functions

An excerpt from sql/04_funnel_analysis.sql. It counts distinct users per stage, then uses LAG and FIRST_VALUE to calculate stage-to-stage conversion and drop-off.

WITH funnel_counts AS (
    SELECT 'signup' AS stage, 1 AS stage_order, COUNT(*) AS users_reached FROM users
    UNION ALL
    SELECT 'search_started', 2, COUNT(DISTINCT user_id) FROM events WHERE event_name = 'search_started'
    UNION ALL
    SELECT 'booking_started', 3, COUNT(DISTINCT user_id) FROM events WHERE event_name = 'booking_started'
    UNION ALL
    SELECT 'booking_completed', 4, COUNT(DISTINCT user_id) FROM events WHERE event_name = 'booking_completed'
),
funnel_with_lag AS (
    SELECT stage, stage_order, users_reached,
           LAG(users_reached)         OVER (ORDER BY stage_order) AS prev_stage_users,
           FIRST_VALUE(users_reached) OVER (ORDER BY stage_order) AS top_of_funnel_users
    FROM funnel_counts
)
SELECT stage, users_reached,
       ROUND(100.0 * users_reached / top_of_funnel_users, 1) AS pct_of_top,
       ROUND(100.0 * (prev_stage_users - users_reached) / prev_stage_users, 1) AS drop_off_pct
FROM funnel_with_lag
ORDER BY stage_order;

Recommendations

  1. Prioritise the search-to-booking step (ride options and comparison) and the Web journey, which converts at 24.0% against 30.0% on iOS.
  2. Shift acquisition budget towards Referral and tighten Paid Search targeting. Judge channels on conversion and ARPU, not signups.
  3. Roll out the simplified booking flow, and keep monitoring conversion and ARPU after launch.
  4. Test engagement prompts (notifications, favourite locations). Their link to retention is observational, so a controlled experiment should confirm it.
